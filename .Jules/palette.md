## 2025-03-02 - [Interactive Elements Inside Clickable Cards]
**Learning:** In `ProductCard.jsx`, interactive elements like the "Add to wishlist" and "Buy now" buttons were nested within a clickable `div` that handles navigation. Without explicit event handling, clicking these nested buttons bubbles up to the parent `div`, causing unintended navigation (a significant UX/accessibility issue for keyboard and mouse users). Additionally, star rating images paired with a text rating redundantly announced "star_icon" to screen readers 5 times.
**Action:** When adding interactive elements inside a clickable container element, always use `onClick={(e) => e.stopPropagation()}` on the nested elements to prevent unintended triggering of the parent's click event. Always add `aria-label` to icon-only buttons. For visual star ratings next to text ratings, hide the container using `aria-hidden="true"` and set the star image `alt` attributes to empty (`alt=""`) to prevent redundant screen reader announcements.
