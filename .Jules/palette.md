## 2024-06-22 - Prevent Redundant Announcements for Visual Ratings and Event Bubbling in Clickable Cards
**Learning:** Found a pattern where visual star ratings paired with numerical text values cause screen readers to redundantly announce "star_icon" 5 times. Additionally, nested interactive elements inside clickable cards bubble up their events, unintentionally triggering the parent card's navigation.
**Action:** When visual UI states like star ratings are paired with explicit text counterparts, always use `aria-hidden="true"` on the visual container and an empty string for `alt` on the visual elements to prevent redundant announcements. For interactive child elements in clickable cards, always add `onClick={(e) => e.stopPropagation()}` to prevent unintended parent navigation.
