## 2024-06-10 - Preventing Redundant Event Triggers and Redundant ARIA Announcements in Product Cards
**Learning:** Adding interactive elements (like a wishlist or "Buy now" button) inside a generic clickable container element like `ProductCard` (which routes users via `onClick`) creates an issue where users are navigated to the product page when they simply meant to interact with a child element. Additionally, rendering repeated icon components (like decorative star ratings) inside a component without proper `aria-hidden` attributes causes the screen reader to redundantly announce "star_icon" 5 times per product card.
**Action:** Always append `.stopPropagation()` to click events of nested interactive elements within full-card click targets. Decorate repeated, non-functional visual elements (like star icons used to represent a rating number already present as text) with `aria-hidden="true"` on the parent container, and remove redundant `alt` text to ensure screen readers only read the rating value once.
