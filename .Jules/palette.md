## 2024-06-12 - ProductCard Accessibility and Interaction Improvements
**Learning:** When interactive elements (like wishlist or buy buttons) are nested inside clickable card containers in Next.js, their click events bubble up and trigger the container's navigation, leading to unintended behavior. Also, rendering repetitive decorative elements (like star ratings) without `aria-hidden` and empty `alt` attributes causes severe screen reader noise (reading "star_icon" 5 times).
**Action:** Always use `onClick={(e) => e.stopPropagation()}` on nested buttons to prevent event bubbling. Always group decorative image arrays in a container with `aria-hidden="true"` and use empty `alt=""` attributes to ensure a clean screen reader experience.
## 2026-07-20 - E-commerce Cart Quantity Input Accessibility
**Learning:** Icon-only plus and minus buttons for cart quantity adjustment lack descriptive screen reader context by default, making it unclear what action the button performs. Furthermore, nested decorative images within these buttons can trigger redundant or unhelpful announcements if not hidden (e.g. `alt="decrease_arrow"`).
**Action:** When adding or auditing quantity adjustments, always ensure the input has an `aria-label="Quantity"` and the respective adjustment buttons have descriptive `aria-label`s (e.g. "Increase quantity"). Apply empty `alt=""` to any inner decorative icons, and explicitly add keyboard navigation focus styles (like `focus-visible:ring-2 outline-none rounded`) to all interactive elements in the control group.
