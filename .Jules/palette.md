## 2024-06-12 - Nested Interactive Elements & Decorative Images
**Learning:** The `ProductCard` component contains an accessibility issue where the outer container is clickable, but has a nested "Add to wishlist" `<button>`. Nesting interactive elements without `e.stopPropagation()` can lead to unexpected behaviors. Also, decorative and redundant star icons in ratings are announced by screen readers if their `alt` text is not empty or `aria-hidden` is missing.
**Action:** Always add `onClick={(e) => e.stopPropagation()}` to buttons nested inside clickable parent `div`s. Hide visual rating icons from screen readers by adding `aria-hidden="true"` to their container and ensuring the individual `<img>` components use empty `alt=""`. Provide proper `aria-label` attributes to icon-only buttons for context.
