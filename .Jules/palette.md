## 2024-06-24 - Accessibility and Nested Interactives in Product Cards
**Learning:** When building visual star ratings paired with text representations (e.g., "4.5"), screen readers will redundantly announce each individual star image if not explicitly hidden. Additionally, placing interactive elements (like a wishlist or "Buy now" button) inside a container that handles click-to-navigate (like a product card `div`) causes nested interaction conflicts and poor UX when a user intends only to trigger the child action.
**Action:** Always use `aria-hidden="true"` on the parent container of purely visual star rating images (and empty `alt=""` text on the images themselves) to prevent redundant a11y announcements. For nested interactive elements within clickable containers, always apply `onClick={(e) => e.stopPropagation()}` to isolate the action and prevent unintended parent navigation.
