## 2024-05-23 - Accessibility for Visual Ratings and Nested Interactive Elements
**Learning:** Screen readers announce every image in a visual rating (like 5 stars) if they have identical `alt` text, creating redundant and noisy announcements. Hiding the entire container with `aria-hidden="true"` and using empty `alt=""` for decorative stars prevents this, allowing the adjacent text rating (e.g., "4.5") to serve as the single source of truth. Additionally, interactive elements (like wishlist or "Buy now" buttons) nested inside a clickable card container will trigger the container's navigation event unless `e.stopPropagation()` is explicitly used. This breaks the intended isolated interactions.
**Action:** Always wrap visual rating images in an `aria-hidden="true"` container with empty `alt` attributes on the images themselves. Always add `onClick={(e) => e.stopPropagation()}` to any interactive elements (buttons, links) nested inside a parent element that also has an `onClick` handler.
