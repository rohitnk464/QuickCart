## 2025-05-19 - Accessibility improvements for repetitive/decorative visual components inside clickable containers
**Learning:** Found that visual star ratings in the e-commerce ProductCard (`assets.star_icon`) were nested inside a clickable div and paired with a text rating (`4.5`), causing redundant readouts to screen readers. In addition, interactive buttons (wishlist, buy now) nested in the clickable container triggered navigation unless `e.stopPropagation()` was utilized.
**Action:** Applied `aria-hidden="true"` and empty string `alt=""` text to visual star rating arrays. Applied `e.stopPropagation()` to internal interactive elements within clickable cards to prevent unwanted parent navigation, alongside typical `aria-label` and `focus-visible:ring-2` for accessibility.
