## 2024-06-25 - Interactive Elements inside Clickable Containers
**Learning:** Adding interactive buttons (like a wishlist or buy button) inside a generic clickable container (like a product card div) without preventing event propagation leads to unintended and frustrating user navigation. Furthermore, visual star ratings paired with text ratings need `aria-hidden` to prevent duplicate screen reader announcements.
**Action:** Always apply `onClick={(e) => e.stopPropagation()}` to child interactive elements within clickable cards to maintain independent interaction paths. Pair visual representations (stars) with text by hiding the visuals (`aria-hidden="true"`, empty `alt` attributes) from screen readers. Add `focus-visible:ring-2 outline-none` to interactive components for clear keyboard accessibility.
