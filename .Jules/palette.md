## 2024-07-08 - Accessible and Independent Buttons inside Clickable Containers
**Learning:** When building reusable Next.js components (like `ProductCard`), interactive elements such as 'Add to Wishlist' or 'Buy Now' buttons are often nested inside a larger clickable container that triggers navigation. Using `e.stopPropagation()` and `e.preventDefault()` on the inner buttons is critical to prevent unintended navigation while triggering the intended action (e.g., `addToCart`). Furthermore, nesting these components dynamically requires the `'use client'` directive at the top of the file to support event handlers. Regarding accessibility, purely decorative icons within these buttons must have empty `alt=''` attributes, and elements like star ratings that provide a visual representation of a text rating should be hidden from screen readers using `aria-hidden='true'` to avoid redundant announcements.
**Action:** Always verify if a button is nested within a clickable wrapper and strictly apply event propagation stoppers to prevent navigation conflicts. Ensure to include the `'use client'` directive when introducing client-side interactions in Server Components. Finally, routinely audit image-based icons and star ratings to apply proper `aria-hidden` and empty `alt` tags for a cleaner screen reader experience.
