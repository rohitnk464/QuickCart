## 2024-06-09 - Accessible and Isolated Interactive Elements in Cards
**Learning:** Found a pattern in `ProductCard.jsx` where interactive elements (`button` for wishlist and 'Buy now') were nested inside a clickable container (`div`) without `e.stopPropagation()`. This caused the parent's click event to fire when the nested buttons were clicked. Additionally, the icon-only wishlist button lacked an `aria-label`, and the visual star ratings were announced redundantly alongside the text rating.
**Action:** Applied `onClick={(e) => e.stopPropagation()}` to nested buttons inside clickable containers. Added `aria-label` to icon-only buttons, `aria-hidden="true"` to visual star containers, and used empty `alt=""` for decorative images. Added `focus-visible:ring-2 focus-visible:outline-none` for keyboard navigation visibility.
