## 2024-07-04 - ARIA attributes and Stop Propagation in Next.js
**Learning:** Adding interactive elements (like a wishlist button or a buy button) inside an overarching clickable container (like ProductCard div) causes nested interactive elements which violate WCAG accessibility guidelines. We need to prevent event propagation when those child elements are clicked. Also missing aria-labels on icon-only buttons makes screen reader users unable to use the feature. Star ratings rendered via images should hide the container with aria-hidden="true" and use empty alt texts, or the whole container should have a textual aria-label while hiding the individual stars to avoid repetitive "star_icon" announcements.
**Action:** Always add aria-labels to icon-only buttons. Always ensure nested interactive actions (like addToCart) use e.stopPropagation().
