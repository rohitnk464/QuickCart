## 2024-05-24 - [Nested Interactive Elements in Next.js App Router]
**Learning:** When modifying client-side Next.js components to include inner click handlers (like wishlist or buy buttons inside a clickable product card div), adding `onClick={(e) => e.stopPropagation()}` is crucial. However, this specifically requires adding the `"use client"` directive to the component file in the App Router architecture, otherwise the application crashes because event handlers cannot be passed to Server Components.
**Action:** Always check if a component is a Server Component (lacks `"use client"`) before adding `onClick` handlers. If it is, either extract the interactive parts to a smaller client component, or add the `"use client"` directive if the whole component needs to be interactive, to prevent build/runtime failures.
