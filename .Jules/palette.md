## 2024-11-21 - Preventing Event Bubbling on Nested Interactive Elements
**Learning:** Adding interactive elements (like a wishlist or "Buy now" button) inside clickable container elements (like the `ProductCard` div) requires `e.stopPropagation()` to prevent unintended triggering of the parent container's click events. Also, visual star ratings paired with a text rating must use `aria-hidden="true"` and empty `alt` attributes to avoid redundant announcements by screen readers.
**Action:** When adding buttons to cards that are already wrapped in an `onClick` handler or `Link`, always include `onClick={(e) => e.stopPropagation()}` and explicitly style them for focus (`focus-visible:ring-2`) and keyboard access, while also addressing redundant visual representations for screen readers.
