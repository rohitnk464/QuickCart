## 2025-06-02 - Nested Interactions and Decorate Elements in Product Cards
**Learning:** The `ProductCard` component structure in this app uses a large clickable outer `div` that handles navigation to product detail pages. Placing interactive elements like the Wishlist and "Buy now" buttons inside this container without proper event management triggers unintended navigation. Additionally, visual star ratings paired with numeric text lead to redundant and confusing screen reader announcements if the star images are not explicitly hidden from assistive technologies.
**Action:** When adding or modifying interactive elements (like buttons) inside an overarching clickable container, always use `onClick={(e) => e.stopPropagation()}` to isolate the event. For visual rating components, wrap the visual-only indicators in an `aria-hidden="true"` container and ensure individual decorative `Image` elements have empty `alt=""` attributes.
