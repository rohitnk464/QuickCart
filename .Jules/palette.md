## 2024-05-08 - Nested Interactive Elements & Redundant Screen Reader Announcements
**Learning:** Adding interactive elements (like a wishlist button) inside clickable container elements (like the ProductCard div) causes unintended triggering of the parent container's click events unless event bubbling is stopped. Additionally, pairing visual indicators (like star ratings) with a text-based rating causes screen readers to redundantly announce the rating multiple times. Nested icons within icon-only buttons also redundantly announce "image" if not hidden from screen readers.
**Action:** Always use `onClick={(e) => e.stopPropagation()}` on interactive elements nested inside clickable containers. Always use `aria-hidden="true"` and empty `alt` attributes (`alt=""`) on decorative images, nested icons, and visual rating indicators that are paired with accessible text.
